# 快速使用指南

## 5分钟快速体验

### 1. 编译程序
```bash
# Windows
build.bat

# Linux/Mac
chmod +x build.sh && ./build.sh
```

### 2. 运行演示程序（推荐新手）
```bash
# Windows
DemoTestCases.exe

# Linux/Mac
./DemoTestCases
```

选择菜单项5可以运行所有演示，查看完整功能效果。

### 3. 运行主程序（自定义数据）
```bash
# Windows
StudentSystemCore.exe

# Linux/Mac
./StudentSystemCore
```

## 常见问题

### Q: 编译失败怎么办？
A: 确保使用C++17或更高版本编译器，检查是否缺少头文件。

### Q: 输入数据格式错误？
A: 程序会提示输入范围，按照提示重新输入即可。

### Q: 如何退出程序？
A: 在主菜单选择退出选项，或按Ctrl+C强制退出。

### Q: 可以保存输入的数据吗？
A: 当前版本不支持数据保存，每次运行需要重新输入。

### Q: 算法结果不理想？
A: 可以调整优先级、权重等参数，或检查输入数据的合理性。
